# 0web.su — сайт компании

Статическая заглушка сайта **2.0web.su**, размещается на GitHub Pages.

## Структура

```
index.html    — единственная страница (заглушка)
styles.css    — стили
favicon.svg   — иконка
CNAME         — привязка к домену 2.0web.su (для GitHub Pages)
.nojekyll     — отключить обработку Jekyll (отдавать файлы как есть)
robots.txt    — правила для поисковых роботов
```

## Публикация

GitHub Pages настроен на ветку `main`, каталог `/` (root). Любой push в `main`
пересобирает сайт автоматически (~1 минута).

## Домены

| Домен | Куда | Где настраивается |
|---|---|---|
| `2.0web.su` | этот репозиторий (GitHub Pages) | `CNAME` + DNS-запись CNAME → `<user>.github.io` |
| `0web.su` | 301-редирект на `https://2.0web.su` | отдельный репозиторий-редиректор на GitHub Pages |

## Локальный просмотр

Достаточно открыть `index.html` в браузере или запустить любой статический сервер:

```bash
python -m http.server 8000
```
